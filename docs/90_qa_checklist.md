# 納品チェックリスト

アセットが AI から返ってきた時に **そのままゲーム投入できるか** を判定するための
機械的チェックリスト。1 項目でも NG なら再発注または post-process が必要。

---

## A. 技術フォーマット（最優先、ここが NG だと使えない）

- [ ] **PNG 形式**（JPG/WEBP は不可）
- [ ] **RGBA チャンネル有**（alpha channel 存在）
- [ ] **背景が完全透過**（画像エディタで背景ピクセル alpha = 0 を確認）
- [ ] **解像度が仕様どおり**（キャラ本体 1024×1024 / アクセサリ 256×256）
- [ ] **sRGB color space**

### A-fallback（透過 PNG が無理な時）

- [ ] 背景が **純白 `#FFFFFF`**（薄い灰 / グラデ / 模様なし）
- [ ] **ground shadow が無い**（足元に灰色の楕円影なし）
- [ ] 白背景とキャラの境界にアンチエイリアスがきつくない

---

## B. キャラクター固定デザイン（`10_character_design.md` 準拠）

### B-1. ちびわふ共通固定要素

以下 **全て visible** であること：

- [ ] 垂れ耳が両サイドに長く垂れてる（**耳長 ≒ 顔の縦幅**）
- [ ] 耳の内側が薄ピンク
- [ ] 頭頂にアホ毛 1 本
- [ ] 前髪（ぱっつん短め）
- [ ] 大きな丸い **茶色** の目、白ハイライト 2 点
- [ ] 頬にピンクの丸い赤み
- [ ] 鼻が極小（点 or 簡素）、目立たない
- [ ] **白いおむつ（下半身を覆う布）に茶色の肉球プリント（中央）**
- [ ] **尻尾は体色のフサフサ、先端に色違いは無い**
- [ ] **尻尾の根元に桃色のリボン**（先端ではなく根元）
- [ ] 体色が温かみのあるクリーム（白すぎない / 黄すぎない）
- [ ] 頭と体のサイズが **ほぼ同じか頭がわずかに大きい**（頭身 2:1 ではない）

### B-2. ちびわふ造形ルール

- [ ] **首が描かれていない**（頭が胴に直結）
- [ ] **肘・膝・肩・足首の関節線が描かれていない**
- [ ] **指・爪・肉球パッドの線が描かれていない**
- [ ] 腕と脚が **ちゃんと見える**（コブだけで終わってない、ただし短い）
- [ ] 人間 chibi / Disney puppy / articulated doll の解剖学になっていない

### B-3. フラナ固有チェック（フラナ発注時）

- [ ] 体色が **クリーム-ホワイト**（ちびわふより白め）
- [ ] 目が **赤** （茶色ではない）、凛として目を開いている
- [ ] **赤い首輪を首元に着用**、正面中央に **金色の鈴** が下がる
- [ ] 白いおむつ + **ピンクの肉球プリント**（ちびわふは茶色、フラナはピンク）
- [ ] 尻尾フサフサ + 根元にピンクリボン（ちびわふと共通）
- [ ] 垂れ耳・内側ピンク・アホ毛・前髪（ちびわふと共通）
- [ ] **エプロンを着ていない**（以前の仕様書誤りで「エプロン必須」と書いてたが正しくは不着用）
- [ ] 体がちびわふより縦長（**頭 ≦ 体** で頭：体 ≒ 0.9-1.0 : 1.0、ちびわふは逆に 頭 > 体）
- [ ] 表情が **凛・クール**（疲れた半目は NG）
- [ ] 造形ルール（首なし・関節なし・指爪なし）は ちびわふと同じ
- [ ] （複数並べた画像での検品時のみ）サイズが並んだ時にちびわふの約 1.8x

---

## C. 絵柄（style）

- [ ] 輪郭線が vector-like にクリア（にじみ禁止）
- [ ] 塗りが flat / cel-shade 寄り
- [ ] watercolor / 水彩 にじみが **ない**
- [ ] 紙の質感テクスチャが **ない**
- [ ] 他の既存 01-09 と並べて違和感ない

---

## D. ポーズ（該当ポーズの合格基準参照）

- [ ] `30_pose_catalog.md` の該当ポーズ「合格基準」を全て満たす
- [ ] ポーズの意図が **一目で読める**
- [ ] 既存 9 ポーズと **キャラ中心位置・足元ライン・スケールが統一**

---

## E. 禁止要素（1 つでもあったら NG）

- [ ] テキスト・ラベル焼き込み（"walk" "run" 等）
- [ ] フレーム・境界線
- [ ] 透かし・署名・ロゴ
- [ ] 他キャラ・背景オブジェクト
- [ ] ドロップシャドウ焼き込み
- [ ] **指・爪・肉球パッド線が描かれている**（手足の先端は単純な丸で終わる）
- [ ] **首の輪郭線・首のくびれが描かれている**
- [ ] **肘・膝・肩・足首の関節線が描かれている**
- [ ] 人間の服・靴

---

## F. アクセサリ単体発注の追加チェック

- [ ] アイテムのみ（ちびわふ本体が描かれていない）
- [ ] 線の太さが本体と **同じ**（並べて確認）
- [ ] 色彩度が本体と **同系統**

---

## G. 検品フロー

```
1. 画像を画像エディタ（Photoshop/GIMP/プレビュー）で開く
2. A. 技術フォーマットをまず確認（NG なら即リトライ）
3. B. キャラ固定要素をスキャン
   - ちびわふ発注時：B-1 + B-2
   - フラナ発注時：B-2 + B-3
4. C. 絵柄をチェック
5. D. ポーズを仕様と照合
6. E. 禁止要素がないか確認
7. 既存キャラの 01_normal.png と横並びで比較：
   - ちびわふ：public/chibiwafu/01_normal.png
   - フラナ：public/furana/01_normal.png
   → 違和感なければ OK
8. NG 項目があれば `50_prompt_templates.md § 6` のリトライ指示を送る
   - ちびわふ固定要素欠け：§6.5
   - フラナ固定要素欠け：§6.6
   - 用語混同（bib/tail tip 等）：§6.7
```

---

## H. よくある NG パターンと対処

| 症状 | 原因 | 対処 |
|---|---|---|
| 背景が白 | 透過 PNG 指定の弱さ | § 6.2 をそのまま貼る |
| 地面影がある | shadow 禁止指定不足 | § 6.3 を貼る + 再生成 |
| 絵本っぽい | style 指定の弱さ | § 6.1 を貼る |
| ポーズが弱い | description が抽象的 | § 6.4 + pose 表現を強調 |
| 耳が短い | 固定要素意識が弱い | § 6.5 を貼る |
| 眼が anime 風 | 既存 reference を見てない | reference を再添付 |
| **首元にスタイを描いた** | 用語混同（bib vs diaper） | § 6.7 を貼る |
| **尻尾の先端がオレンジ** | 用語混同（tip vs base） | § 6.7 を貼る |
| **フラナにエプロンが描かれた** | 旧仕様書の古い記述に引きずられ | § 6.6 を貼る |
| **フラナの目が茶色** | ちびわふからの継承誤解 | § 6.6 を貼る（赤目強調） |
| **首・肘・膝の線が描かれた** | articulated body 解釈 | § 6.5 を貼る、造形ルール強調 |
| **指・爪が描かれた** | 解剖学的 chibi 解釈 | § 6.5 を貼る |
| 4-grid ラベル入り | output format 指定不足 | § 4 の最後の注意を強調 |
| 顔がブレる（複数発注） | 個別発注の限界 | バッチ（§ 4）に切替 |

---

## I. 合格判定のコツ

**3 秒ルール**：パッと見て「既存 01-09 と一緒にスプライトシート化しても違和感ない」と
言えたら合格。迷ったら NG 寄せ。

**並べテスト**：既存 01_normal.png と新規ポーズを横に並べて縮小表示（実ゲームサイズ 48-80px）。
ゲーム内サイズで見て識別できないと実運用で破綻する。

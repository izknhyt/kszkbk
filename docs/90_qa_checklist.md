# 納品チェックリスト

アセットが AI から返ってきた時に **そのままゲーム投入できるか** を判定するための
機械的チェックリスト。1 項目でも NG なら再発注または post-process が必要。

---

## A. 技術フォーマット（最優先、ここが NG だと使えない）

- [ ] **PNG 形式**（JPG/WEBP は不可）
- [ ] **RGBA チャンネル有**（alpha channel 存在）
- [ ] **背景が完全透過**（画像エディタで背景ピクセル alpha = 0 を確認）
- [ ] **解像度が仕様どおり**（キャラ本体 1024×1024 / アクセサリ 256×256）
- [ ] **sRGB color space**

### A-fallback（透過 PNG が無理な時）

- [ ] 背景が **純白 `#FFFFFF`**（薄い灰 / グラデ / 模様なし）
- [ ] **ground shadow が無い**（足元に灰色の楕円影なし）
- [ ] 白背景とキャラの境界にアンチエイリアスがきつくない

---

## B. キャラクター固定デザイン（`10_character_design.md` 準拠）

### B-1. ちびわふ共通固定要素

以下は固定デザイン要素。ただし、該当ポーズの構図・表情・変形で自然に隠れる/
変形するものは `30_pose_catalog.md` のポーズ指示を優先する。
無理に全要素を正面へ見せるために、ポーズ可読性を壊さないこと。

- [ ] 垂れ耳が両サイドにあり、`00_origin.png` と同じ横広シルエット
- [ ] 耳の内側が見える角度では薄ピンク。見えない角度のポーズで無理に見せていない
- [ ] 耳が `00_origin.png` と同じ **横広の垂れ耳デザイン**（長い縦耳・巨大丸耳ではない）
- [ ] 頭頂にアホ毛 1 本（`00_origin.png` と同じ低く後ろへ流れるカール）
- [ ] 前髪（`00_origin.png` と同じ小さい房。厚いカーテン前髪にしない）
- [ ] 大きな縦楕円の **茶色〜橙茶** の目、白目の余白と白ハイライト
  （閉じ目・x_x・><・涙目などは該当ポーズの表情指示を優先）
- [ ] 頬にピンクの丸い赤み
- [ ] 鼻が極小（点 or 簡素）、目立たない
- [ ] **白いおむつ（下半身を覆う布）に茶色の肉球プリント（中央）**
  （`18_drown_flail` など、下半身が構図上見えないポーズは例外）
- [ ] **尻尾は体色のフサフサ、先端に色違いは無い**
- [ ] **尻尾の根元に小さくコンパクトな桃色のリボン/結び**（先端ではなく根元。
  大きな蝶結び・ハート形・花びら形ではない。構図上隠れる場合はポーズ指示を優先）
- [ ] 体色が温かみのあるクリーム（白すぎない / 黄すぎない）
- [ ] 頭が体より **明確に大きい**が、`00_origin.png` より頭・顔が横太り、
  風船化、巨大化していない
- [ ] 顔・目・鼻・口・頬・前髪・耳・アホ毛が `00_origin.png` と同一キャラデザインに見える

### B-2. ちびわふ造形ルール

- [ ] **首が描かれていない**（頭が胴に直結）
- [ ] **肘・膝・肩・足首の関節線が描かれていない**
- [ ] **指・爪が描かれていない**
- [ ] 見える手足先端に **小さなピンク肉球パッド** がある
  （指分割・爪・リアルな犬足裏ではない）
- [ ] 腕と脚が **ちゃんと見える**が、`00_origin.png` と同じぬいぐるみ手足の短さ
  （chest-down crop、splat、横寝など、該当ポーズで隠れる/潰れる場合はポーズ指示を優先）
- [ ] 人間 chibi / Disney puppy / articulated doll の解剖学になっていない

### B-3. フラナ固有チェック（フラナ発注時）

- [ ] 体色が **クリーム-ホワイト**（ちびわふより白め）
- [ ] 目が **赤** （茶色ではない）、凛として目を開いている
- [ ] **赤い首輪を首元に着用**、正面中央に **金色の鈴** が下がる
- [ ] 白いおむつ + **ピンクの肉球プリント**（ちびわふは茶色、フラナはピンク）
- [ ] 尻尾フサフサ + 根元にピンクリボン（ちびわふと共通）
- [ ] 垂れ耳・内側ピンク・アホ毛・前髪（ちびわふと共通）
- [ ] **エプロンを着ていない**（以前の仕様書誤りで「エプロン必須」と書いてたが正しくは不着用）
- [ ] 体がちびわふよりやや縦長だが、**頭は依然として体より大きい**
  （フラナ：頭：体 ≒ 1.2:1、頭 55% / 胴 35% / 脚 10%。ちびわふは `00_origin.png` のデザイン性優先で頭 55-60% 目安）
- [ ] 表情が **凛・クール**（疲れた半目は NG）
- [ ] 造形ルール（首なし・関節なし・指爪なし）は ちびわふと同じ
- [ ] （複数並べた画像での検品時のみ）サイズが並んだ時にちびわふの約 1.8x

## C. 絵柄（style）

- [ ] 紙の質感テクスチャが **ない**

## D. ポーズ（該当ポーズの合格基準参照）

- [ ] ポーズの意図が **一目で読める**
- [ ] ゲーム内で状態スプライトとして差し替えた時に、同一キャラの別状態として読める
- [ ] 既存 9 ポーズと **キャラ中心位置・足元ライン・スケールが統一**
  （`30_pose_catalog.md` で足元ライン例外が明記されたポーズは除く）
- [ ] walk_lean では、歩行表現のために手足が長くなっていない
- [ ] walk_lean では、通常立ちポーズのコピーではなく、短いぬいぐるみ足の前後差・軽い前傾が目視で分かる
- [ ] `05_sulking.png` は純睡眠として扱わない（転んだ瞬間・へたり込み・すね倒れに見える）
- [ ] `08_sleepy.png` は純睡眠として扱わない（殴られ後・昏睡しかけ・意識もうろうに見える）
- [ ] `28_sleep_curl` / `29_sleep_flat` / `30_nap_sitting` は穏やかな純睡眠に見え、死亡・昏睡・ボコ後に見えない
- [ ] 純睡眠ポーズでは x_x 目・舌出し・衝撃星・あざ・流血・Zzz 文字がない
- [ ] `13_hold_stick` の小物は小枝サイズで、長い棒・杖・武器に見えない
- [ ] `18_drown_flail` だけは chest-down crop のため下半身/おむつが見えなくてもよい
- [ ] `25_grabbed` では外部の人間の手・神の手を描いていない
- [ ] `26_thrown_airborne` では impact star を描かず、`19_knocked` と混同しない
- [ ] `31_wake_up` は座ったままの起床直後に見え、純睡眠・昏睡・負傷と混同しない
- [ ] `32_plead` は外部小物・後光・祈り記号なしでお願い/許し乞いに見える
- [ ] `33_celebrate_jump` は喜びジャンプに見え、`17_arms_up` の落下/絶叫と混同しない。キラキラ・紙吹雪なし
- [ ] `34_sick_fever` は座り込んだ病気・発熱に見え、片手が額に触れていて、死亡・昏睡・ボコ後に見えない
- [ ] `35_smoke_cough` は小さな煙記号だけで、火・室内・煙背景を描いていない
- [ ] `36_dig_scrape` / `37_gather_pickup` は invisible ground plane 前提で、地面・畑・床背景を描いていない
- [ ] `37_gather_pickup` の小物は小さく 1 個までで、籠・畑・収穫背景を描いていない
- [ ] `38_refuse_no` はテキストや禁止マークなしで拒否に見え、人間的な腕組みになっていない
- [ ] `39_search_look` は虫眼鏡・地図・疑問符なしで探索に見える
- [ ] `40_lonely_sit` は静かな寂しさに見え、号泣・居眠り・怪我と混同しない

## E. 禁止要素（1 つでもあったら NG）

- [ ] テキスト・ラベル焼き込み（"walk" "run" 等）
- [ ] フレーム・境界線
- [ ] 透かし・署名・ロゴ
- [ ] 他キャラ・背景オブジェクト
- [ ] ドロップシャドウ焼き込み
- [ ] **指・爪が描かれている**
- [ ] 手足の肉球が、指分割・爪・リアルな犬足裏のように描かれている
- [ ] **首の輪郭線・首のくびれが描かれている**
- [ ] **肘・膝・肩・足首の関節線が描かれている**
- [ ] 人間の服・靴

## F. アクセサリ単体発注の追加チェック

## G. 検品フロー

```
1. 画像を画像エディタ（Photoshop/GIMP/プレビュー）で開く
2. A. 技術フォーマットをまず確認（NG なら即リトライ）
3. B. キャラ固定要素をスキャン
   - ちびわふ発注時：B-1 + B-2
   - フラナ発注時：B-2 + B-3
4. C. 絵柄をチェック
5. D. ポーズを仕様と照合
6. E. 禁止要素がないか確認
7. 生成用 visual reference と横並びで比較：
   - ちびわふ：public/chibiwafu/00_origin.png
   - フラナ：public/furana/01_normal.png
   → キャラデザイン同一性に違和感がなく、かつポーズ差分が読めれば OK
8. 既存ゲーム内スプライト（ちびわふの `01_normal.png` など）とも必要に応じて縮小比較：
   - これは QA 比較であり、画像生成時の添付 reference を増やす意味ではない
   - 既存 01-09 と並べて、線幅・色味・スケール・状態差分がゲーム内で破綻しないかを見る
9. NG 項目があれば `50_prompt_templates.md § 6` のリトライ指示を送る
   - ちびわふ固定要素欠け：§6.5
   - フラナ固定要素欠け：§6.6
   - 用語混同（bib/tail tip 等）：§6.7
```

## H. よくある NG パターンと対処

| 症状 | 原因 | 対処 |
|---|---|---|
| 背景が白 | 透過 PNG 指定の弱さ | § 6.2 をそのまま貼る |
| 市松模様が見える | 透明プレビュー柄が実ピクセルとして焼き込まれている | 技術 A で NG。RGBA 透過 PNG として再出力 |
| 地面影がある | shadow 禁止指定不足 | § 6.3 を貼る + 再生成 |
| 絵本っぽい | style 指定の弱さ | § 6.1 を貼る |
| ポーズが弱い | description が抽象的 | § 6.4 + pose 表現を強調 |
| 耳の形が違う | 00_origin.png の横広耳ではなく汎用マスコット耳に寄った | § 6.5 を貼る |
| 顔が別キャラ | 00_origin.png の顔・目・前髪・アホ毛・耳のデザイン性を維持できていない | § 6.8 を貼る。過去 NG 画像を参照から外す |
| 顔が横太り/風船化 | 「頭が大きい」指示が強すぎる | § 6.8 を貼り、頭幅・顔幅は 00_origin.png のデザイン性に合わせると指定 |
| 眼が anime 風 | 既存 reference を見てない | reference を再添付 |
| walk_lean で脚が長い | mid-stride を解剖学的な歩行脚として解釈 | § 6.9 を貼る |
| walk_lean で肘・膝っぽい曲がり | 歩行表現を関節で描いている | § 6.9 を貼る |
| **首元にスタイを描いた** | 用語混同（bib vs diaper） | § 6.7 を貼る |
| **尻尾の先端がオレンジ** | 用語混同（tip vs base） | § 6.7 を貼る |
| **手足のピンク肉球がない** | 旧仕様の「肉球パッド禁止」に引っ張られている | 手足先端には小さなピンク肉球パッドを描く。指・爪・リアル足裏にはしない |
| **おむつの茶色肉球プリントがない** | 手足肉球とおむつプリントを混同している | 手足先端のピンク肉球と、おむつ中央の茶色肉球プリントを両方描く |
| **尻尾リボンが大きな蝶結び/ハート** | root ribbon を装飾アクセサリとして誇張 | § 6.8 を貼る。小さい根元リボン/結びと指定 |
| 過去の失敗画像に似る | 同じ会話/生成 UI 内の NG 画像に引っ張られている | 新規セッションで生成用 visual reference だけを添付して再生成（ちびわふは `00_origin.png`） |
| walk_lean が通常立ちに見える | reference identity をピクセル固定/立ち姿固定として解釈している | § 6.4 + § 6.9 を貼り、短い足の前後差と軽い前傾を明確化 |
| `13_hold_stick` が長い棒・杖になる | stick を staff と解釈している | `30_pose_catalog.md` §13 の小枝指示を貼り、小枝は体より長くないと明記 |
| `25_grabbed` に人間の手が描かれた | つままれを場面絵として解釈している | 外部の手はエンジン側/演出側で扱うため、キャラ反応だけ描くと指定 |
| `28-30` が死亡・昏睡に見える | sleep と knocked/dead/exhausted の記号が混ざっている | x_x 目・舌出し・衝撃星・あざ・Zzz 文字を禁止し、穏やかな閉じ目にする |
| `18_drown_flail` の下半身がない | chest-down crop の仕様 | これは仕様どおり。全身が必要な他ポーズと混同しない |
| `34_sick_fever` が死亡・昏睡に見える | 病気表現に x_x 目・舌出し・衝撃記号が混ざっている | ぐったり弱い表情に留め、死亡/衝撃記号を禁止する |
| `34_sick_fever` が `27_weather_suffering` に見える | 汗・つらい表情だけで病気専用シルエットがない | 座り姿勢に固定し、片手を額に触れさせ、頬の赤みを強める |
| `33_celebrate_jump` が紙吹雪/キラキラ背景になる | celebrate を装飾で説明している | 装飾星・紙吹雪を禁止し、砂煙は体の近く 1-2 個まで |
| `38_refuse_no` が人間的な腕組みになる | arms crossed が長腕・肘を誘発している | 短い丸手を腹前にぎゅっと寄せる拒否姿勢に戻す |
| `32_plead` に後光・祈り小物が描かれた | plead を宗教的/儀式的に解釈している | 両手を胸/腹前で合わせるキャラ動作だけに戻す |
| `35_smoke_cough` に火や部屋が描かれた | smoke/fire を場面絵として解釈している | 小さな煙記号と咳き込み姿勢だけに戻す |
| `36/37` に地面・畑・床が描かれた | ground plane を背景として描いている | invisible ground plane と明記し、キャラ単体スプライトへ戻す |
| `39_search_look` に虫眼鏡や地図が描かれた | 探索を小物で説明している | 小物なし、片手を目の上に添える姿勢で表現する |
| **フラナにエプロンが描かれた** | 旧仕様書の古い記述に引きずられ | § 6.6 を貼る |
| **フラナの目が茶色** | ちびわふからの継承誤解 | § 6.6 を貼る（赤目強調） |
| **首・肘・膝の線が描かれた** | articulated body 解釈 | § 6.5 を貼る、造形ルール強調 |
| **指・爪が描かれた** | 解剖学的 chibi 解釈 | § 6.5 を貼る |
| 4-grid ラベル入り | output format 指定不足 | § 4 の最後の注意を強調 |
| 顔がブレる（複数発注） | 個別発注の限界 | バッチ（§ 4）に切替 |

## I. 合格判定のコツ

**3 秒ルール**：パッと見て「既存 01-09 と一緒にスプライトシート化しても違和感ない」と
言えたら合格。迷ったら NG 寄せ。

**並べテスト**：生成用 visual reference（ちびわふは `00_origin.png`）と新規ポーズを
横に並べて縮小表示（実ゲームサイズ 48-80px）。その後、既存ゲーム内スプライト
（例：ちびわふ `01_normal.png`）とも比較する。前者ではキャラデザイン同一性と
ポーズ差分、後者ではゲーム内での線幅・色味・スケール・足元ラインの安定性を見る。

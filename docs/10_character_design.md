# キャラクターデザイン仕様

既存 01-09 の絵柄を **唯一の真実の源（source of truth）** とする。
新規発注は全て既存 PNG と並べて違和感が出ない状態を合格基準とする。

**リファレンス画像（発注時に必ず添付）**：
- `public/chibiwafu/01_normal.png`（ちびわふ基準）
- `public/furana/01_normal.png`（フラナ基準）

## 1. ちびわふ（Chibiwafu）

### 1.1 種族定義

- 垂れ耳のプードル風のちびもの
- 2D ゲーム用の chibi / SD 頭身
- 口語では「くそざこ」「ちびわふ」
- 語尾は「〜わふ」

### 1.2 プロポーションと造形（**最重要・厳守**）

**全体シルエット = 卵型／丸型のブロブ**。
Disney の puppy character や anime の chibi のような articulated body ではない。
Sanrio キャラ（ポチャッコ・シナモロール）/ Kirby / マシュマロ にイメージが近い、
**「ほぼ球体に小さい突起がついた」だけの形**。

⚠ AI に「chibi」「puppy」とだけ言うと、自分のテンプレで articulated body
（肘・膝・首・長い手足を持つ）を描いてしまう。**この § 1.2 全文を必ず
発注プロンプトに含めて、形を明示的に固定する**。

#### 1.2.1 頭身比（逆転頭身）

| 部位 | 全身に占める縦の割合 | 備考 |
|---|---|---|
| 頭部（耳の上端まで） | **約 60%** | **頭が体より大きい** |
| 胴体 | **約 30%** | 短い樽型 |
| 露出する脚部 | **約 10%** | コブ程度、ほぼ胴に埋まる |

**頭：体 比 = 1.2 : 0.8**（頭の方が大きい逆転頭身）。
「2 頭身」と書くと「人間の 2 頭身」に解釈されるので **「頭が体より大きい」**
と必ず明記する。

#### 1.2.2 首

**ない**。頭が胴の上に直接乗っている。首の輪郭線・首のくびれは描かない。
Hello Kitty / Pochacco のように頭と体が直結する。

#### 1.2.3 手足の造形（**最も誤解されやすい**）

**全ての手足が「肉球コブ」レベルの極小**。関節を持たない。

| 部位 | 仕様 |
|---|---|
| 前足（腕） | 胴の側面からごく短い丸い突起が出る程度。長さ ≦ 胴幅の **25%**。肘・肩なし |
| 後足（脚） | 胴の下端に直接 2 つの丸い小球がついている。膝・足首なし |
| 手の先 | **指なし**、爪なし、肉球パッドの線描なし。先端は単純な「○」で終わる |
| 足の先 | 同上、丸く終わる |

**腕や脚が「伸びる」「曲がる」描写は最小限**。Action ポーズでも腕は
胴の横にちょこんと出るだけ、脚は下端からちょこんと出るだけ。

#### 1.2.4 立ち姿勢

脚が極端に短いため、**立ち姿でも常に「ちょっとしゃがんでいる」ように見える**
のが正解。4 足獣が立ち上がった姿でも、人型 chibi の立ち姿でもなく、
**「丸いだるまが下端に小さい脚を出している」**イメージ。

#### 1.2.5 耳

| 項目 | 仕様 |
|---|---|
| 長さ | **顔の縦幅とほぼ同じ**（顎の位置まで届く） |
| 幅 | 顔幅の約 30% |
| 形 | 楕円が下に垂れ下がる、先端は丸い |
| 位置 | 頭頂の左右、前髪の生え際よりやや上 |

**耳が顔と同じくらいデカい** = キャラ識別の核。耳を短くしたら別キャラ。

#### 1.2.6 全身のキャンバス内サイズ

| 項目 | 仕様 |
|---|---|
| 全身高 | キャンバス高の **約 70%** |
| 上下マージン | 各約 15% |
| 体幹中心位置 | キャンバス中央 |
| 足元基準ライン | キャンバス底から 15% |

#### 1.2.7 シルエットの自己チェック

完成画像のシルエット（黒塗り）を見て以下が成立するか確認：

- [ ] 全体が **丸い卵型** に近い
- [ ] 頭の幅 ≧ 胴の幅
- [ ] 首の細まりがない
- [ ] 手脚が **シルエットからほぼ突き出ていない**（出ても短いコブ）
- [ ] 耳が **顔と同じくらいデカい影**として見える
- [ ] 全体が **マシュマロ** や **だるま** の輪郭に近い

### 1.3 固定デザイン要素（**変更禁止**）

以下の要素は **どのポーズ・どの emotion でも必ず描かれる**。
新規発注で欠けていたら不合格。

| 要素 | 仕様 | 色域 |
|---|---|---|
| 体毛 | クリーム色のふわふわ | `#F5E6D3` ± 5% |
| 垂れ耳 | 顔の両サイドに長く垂れる、内側は薄いピンク | 外：体色 / 内：`#F5D5D0` |
| アホ毛 | 頭頂から 1 本ぴょこっと立つ | 体色と同じ |
| 前髪 | 目の上に短いぱっつん | 体色と同じ |
| 目 | 大きな丸、黒茶瞳に白ハイライト 2 点 | `#4A2A1A` / 白 |
| 頬 | 左右に薄ピンクの丸い頬染め | `#F5B5B0` |
| 鼻 | 小さい三角、ごく控えめ | `#3A2A1A` |
| スタイ（よだれかけ） | 白地に茶色の肉球プリント | 地：白 / プリント：`#8B5A2B` |
| 尻尾 | 短め、先端がオレンジ/桃の小球 | 体色 + 先端 `#F2A576` |

### 1.4 個体差として変えて OK な要素

後段で runtime 合成するため、**基本 PNG では付けない**。
ただし **将来的な色 tint の幅として以下は許容**：

| 要素 | 個体差の幅 |
|---|---|
| 体色 tint | hue ±15°、saturation ±10%（中間色のみ、原色は NG） |
| サイズ | 0.9x - 1.1x |
| 装備小物（後述） | 帽子・鉢巻・メガネ等を overlay レイヤーで追加 |

### 1.5 表情の描き分け原則

感情ごとに以下を変える：

| 感情軸 | 変える部位 |
|---|---|
| 目 | 丸開き / 細目 / ハの字 / x_x / 涙目 / ぐるぐる |
| 口 | 閉じ / 笑み / Ω / 三角 / 舌出し |
| 眉 | （通常は見えない、必要な時のみ前髪の隙間から） |
| 頬 | 赤み強弱 |

既存 01-09 の顔の描き分けを参照して踏襲する。

## 2. フラナ（Furana / ママ）

### 2.1 種族定義

- ちびわふの大人形態（ママ）
- 同種族なので基本デザインは共通
- 語尾は同じく「〜わふ」

### 2.2 ちびわふとの差分

**造形は § 1.2 と完全に同じ**（卵型ブロブ、首なし、関節なし、コブ手足）。
ちびわふを **そのまま 1.8x に拡大** したものを基本に、以下を差し替える：

| 要素 | 差分 |
|---|---|
| サイズ | ちびわふの **1.8x**（造形ルールはそのまま、形のスケーリングのみ） |
| 頭身比 | § 1.2.1 と同じ（頭が体より大きい逆転頭身を維持） |
| 目 | 同形だが、少し疲れた半目気味 |
| 表情 | 優しげ、穏やか、少し疲労感 |
| 装備 | **エプロン**（白地、腰紐は薄ピンク）を常時着用 |
| その他 | 基本デザイン（耳・尻尾・スタイ・アホ毛）は全て同じ |

⚠ フラナだからといって **大人体型に寄せない**（首・くびれ・長い手足は NG）。
あくまで「巨大化したちびわふ」。

### 2.3 リファレンス

- `public/furana/01_normal.png` が基準
- ちびわふと一緒に写る時のスケール比確認は既存画像で検証

## 3. 禁則事項（アンチデザイン）

発注時に **明示的に排除するキーワード**：

| カテゴリ | NG 要素 |
|---|---|
| 絵柄 | watercolor / storybook / picture book / painterly / sketchy / crayon |
| 画風 | photorealistic / 3D render / anime-only / manga-only |
| **造形（最重要）** | **首を描く** / **肘・膝・関節を描く** / **指を描く** / **爪を描く** |
| **造形** | **腕や脚を細長くする** / **人間体型にする** / **腰のくびれを描く** |
| **造形** | **頭を体より小さくする** / **シルエットを縦長にする** / **頭身を 2:1 以上にする** |
| **造形** | **4 足歩行ポーズ**（基本は 2 足立ち or 座り、ただし丸いまま） |
| **造形** | **articulated body / posable doll の解剖学**（puppet 的なリアルプロポーション） |
| キャラ | 人間の服を着せる / 靴を履かせる / 武器（小物以外） |
| 変形 | 耳を短くする / 尻尾を長くする / 体色を原色にする |
| 構造 | 指の表現 / 瞳孔を細くする / 歯を見せる（舌は OK） |
| 背景 | 環境背景を描く（単体発注時）/ ground shadow 焼き込み |

## 4. この仕様書の使い方

発注時は以下の順でプロンプトを組む：

```
[50_prompt_templates.md からマスタープロンプト]
 ↓
[10_character_design.md から 1.3 固定デザイン要素の表]
 ↓
[10_character_design.md から 3. 禁則事項]
 ↓
[30_pose_catalog.md から該当ポーズ記述]
 ↓
[20_technical_spec.md から納品形式要件]
 ↓
添付: public/chibiwafu/01_normal.png
```

プロンプト全体は 500-800 words に収まる設計。

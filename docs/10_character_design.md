# キャラクターデザイン仕様

既存 01-09 の絵柄を **唯一の真実の源（source of truth）** とする。
新規発注は全て既存 PNG と並べて違和感が出ない状態を合格基準とする。

**リファレンス画像（発注時に必ず添付）**：
- `public/chibiwafu/01_normal.png`（ちびわふ基準）
- `public/furana/01_normal.png`（フラナ基準）

---

## 1. ちびわふ（Chibiwafu）

### 1.1 種族定義

- 垂れ耳のプードル風のちびもの
- 2D ゲーム用の chibi / SD 頭身
- 口語では「くそざこ」「ちびわふ」
- 語尾は「〜わふ」

### 1.2 プロポーション

| 部位 | 仕様 |
|---|---|
| 頭身 | 2:1（頭が体と同じか少し大きい） |
| 全身高（キャンバス内） | キャンバス高の約 70% |
| 頭：耳長 | 耳は顔の縦幅とほぼ同じ長さ、両サイドに垂れる |
| 手脚 | 短く丸いスタブ、指は表現しない |

### 1.3 固定デザイン要素（**変更禁止**）

以下の要素は **どのポーズ・どの emotion でも必ず描かれる**。
新規発注で欠けていたら不合格。

| 要素 | 仕様 | 色域 |
|---|---|---|
| 体毛 | クリーム色のふわふわ | `#F5E6D3` ± 5% |
| 垂れ耳 | 顔の両サイドに長く垂れる、内側は薄いピンク | 外：体色 / 内：`#F5D5D0` |
| アホ毛 | 頭頂から 1 本ぴょこっと立つ | 体色と同じ |
| 前髪 | 目の上に短いぱっつん | 体色と同じ |
| 目 | 大きな丸、黒茶瞳に白ハイライト 2 点 | `#4A2A1A` / 白 |
| 頬 | 左右に薄ピンクの丸い頬染め | `#F5B5B0` |
| 鼻 | 小さい三角、ごく控えめ | `#3A2A1A` |
| スタイ（よだれかけ） | 白地に茶色の肉球プリント | 地：白 / プリント：`#8B5A2B` |
| 尻尾 | 短め、先端がオレンジ/桃の小球 | 体色 + 先端 `#F2A576` |

### 1.4 個体差として変えて OK な要素

後段で runtime 合成するため、**基本 PNG では付けない**。
ただし **将来的な色 tint の幅として以下は許容**：

| 要素 | 個体差の幅 |
|---|---|
| 体色 tint | hue ±15°、saturation ±10%（中間色のみ、原色は NG） |
| サイズ | 0.9x - 1.1x |
| 装備小物（後述） | 帽子・鉢巻・メガネ等を overlay レイヤーで追加 |

### 1.5 表情の描き分け原則

感情ごとに以下を変える：

| 感情軸 | 変える部位 |
|---|---|
| 目 | 丸開き / 細目 / ハの字 / x_x / 涙目 / ぐるぐる |
| 口 | 閉じ / 笑み / Ω / 三角 / 舌出し |
| 眉 | （通常は見えない、必要な時のみ前髪の隙間から） |
| 頬 | 赤み強弱 |

既存 01-09 の顔の描き分けを参照して踏襲する。

## 2. フラナ（Furana / ママ）

### 2.1 種族定義

- ちびわふの大人形態（ママ）
- 同種族なので基本デザインは共通
- 語尾は同じく「〜わふ」

### 2.2 ちびわふとの差分

| 要素 | 差分 |
|---|---|
| サイズ | ちびわふの **1.8x** |
| プロポーション | 2.2:1 頭身（やや縦長に寄せる） |
| 目 | 同形だが、少し疲れた半目気味 |
| 表情 | 優しげ、穏やか、少し疲労感 |
| 装備 | **エプロン**（白地、腰紐は薄ピンク）を常時着用 |
| その他 | 基本デザイン（耳・尻尾・スタイ・アホ毛）は全て同じ |

### 2.3 リファレンス

- `public/furana/01_normal.png` が基準
- ちびわふと一緒に写る時のスケール比確認は既存画像で検証

---

## 3. 禁則事項（アンチデザイン）

発注時に **明示的に排除するキーワード**：

| カテゴリ | NG 要素 |
|---|---|
| 絵柄 | watercolor / storybook / picture book / painterly / sketchy / crayon |
| 画風 | photorealistic / 3D render / anime-only / manga-only |
| キャラ | 人間の服を着せる / 靴を履かせる / 武器（小物以外） |
| 変形 | 耳を短くする / 尻尾を長くする / 体色を原色にする |
| 構造 | 指の表現 / 瞳孔を細くする / 歯を見せる（舌は OK） |
| 背景 | 環境背景を描く（単体発注時）/ ground shadow 焼き込み |

## 4. この仕様書の使い方

発注時は以下の順でプロンプトを組む：

```
[50_prompt_templates.md からマスタープロンプト]
 ↓
[10_character_design.md から 1.3 固定デザイン要素の表]
 ↓
[10_character_design.md から 3. 禁則事項]
 ↓
[30_pose_catalog.md から該当ポーズ記述]
 ↓
[20_technical_spec.md から納品形式要件]
 ↓
添付: public/chibiwafu/01_normal.png
```

プロンプト全体は 500-800 words に収まる設計。

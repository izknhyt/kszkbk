# キャラクターデザイン仕様

ちびわふの新規生成では `00_origin.png` の **キャラクターデザイン性** を
生成用 visual reference の正本とする。既存 01-09 はゲーム内スプライトとしての
互換性・絵柄・線幅・状態差分を確認する QA 基準であり、新規発注は既存 PNG と
並べて違和感が出ない状態を合格基準とする。

**生成用 visual reference 画像（発注時に添付する画像）**：
- `public/chibiwafu/00_origin.png`（ちびわふ基準）
- `public/furana/01_normal.png`（フラナ基準）

ここでいう「リファレンス画像」は、画像生成ツールへ添付する visual reference を指す。
既存ポーズ画像（ちびわふの `01_normal.png` など）は、ゲーム内スプライトとの並び確認、
表情・線幅・実装上の互換性確認、更新履歴の理解には使ってよい。ただし、ちびわふの
新規ポーズ生成時に追加の visual reference として添付する画像は `00_origin.png` のみにする。

> ⚠ **ちびわふとフラナは別体型**。フラナは「ちびわふの拡大版」ではなく、
> プロポーション・装備・目の色が違う別キャラクター。§ 1 と § 2 を独立に読む。

## 1. ちびわふ（Chibiwafu）

### 1.1 種族定義

- 垂れ耳のプードル風の ちびもの
- 2D ゲーム用の chibi / SD 頭身
- 口語では「くそざこ」「ちびわふ」
- 語尾は「〜わふ」

### 1.2 プロポーションと造形

`public/chibiwafu/00_origin.png` の **キャラクターデザイン性** を唯一の正本とする。
これは画像生成時の visual reference としての正本であり、ピクセル配置・輪郭・立ちポーズを
固定するという意味ではない。
以下の数値・比率は全て「00_origin.png のキャラに見えるための補助」であり、
実画像のデザイン特徴と矛盾した場合は **必ず実画像のデザイン特徴を優先** する。

ポーズ発注では、顔の設計・横広耳・頭上シルエット・前髪・アホ毛・短い手足・
おむつ・尻尾根元リボンを維持する。一方で、腕脚や胴体の位置はポーズを一目で
読ませるために描き直してよい。`00_origin.png` と同じピクセル配置や通常立ち姿を
維持する必要はない。

`00_origin.png` のような「ずんぐり立ち chibi」だが、**シナモロールの長い縦耳や、
一般的な犬キャラの解剖学へ寄せない**。Kirby のような純ブロブでもなく、
Disney puppy のような articulated body でもない。ちゃんと 2 本足で立つが、
手足は **ぬいぐるみの短い付属肢** くらい短く、関節を持たない。

#### 1.2.1 頭身比

| 部位 | 全身に占める縦の割合 |
|---|---|
| 頭部（耳の上端まで） | 約 **55-60%** |
| 胴体 | 約 **30-35%** |
| 脚部（露出） | 約 **10%** |

**頭：体（胴+脚）比 ≒ 1.5 : 1**（頭が体より明確に大きい）。
ただし、頭を風船のように巨大化したり、顔を横に太らせたりしない。
`00_origin.png` と同じ **横長すぎない丸頭・少し平たい下顔** を保つ。
「2 頭身」「3 頭身」と書くと人間 chibi 解釈されるので、発注時は
**「00_origin.png の頭身・頭幅・顔幅のデザイン性を維持」** と明記する。

#### 1.2.2 首

**描かない**。頭が胴の上に直接乗る。首の輪郭線・首のくびれは NG。
Hello Kitty / ポチャッコ のように頭と体が直結。

#### 1.2.3 手足

**ちゃんと 2 本の腕と 2 本の脚が生えている**、ただし：

| 部位 | 仕様 |
|---|---|
| 腕 | 胴の脇から生える短いぬいぐるみ腕。長さは `00_origin.png` の短さの範囲（胴の縦半分以下）。肘・肩の関節線は描かない |
| 脚 | 胴の下から 2 本明確に出る短いぬいぐるみ足。露出は短く、`00_origin.png` の足のデザイン性に合わせる。膝・足首の線は描かない |
| 手の先 | **指なし・爪なし**。短い丸手の先に、自然に見える範囲で小さなピンクの肉球パッドを描く |
| 足の先 | **指なし・爪なし**。短い丸足の先に、小さなピンクの肉球パッドを描く |

**スタブ（切り株）的な "肉球コブ" ではなく、短いぬいぐるみ手足**。
腕は振れるし、脚は立てるが、歩行ポーズでも長い犬脚や人間 chibi 脚にしない。
ただし解剖学的な関節線は描かない。肉球は **ピンクの小さなパッド** として描き、
指・爪・長い手指・犬のリアルな足裏にはしない。

#### 1.2.4 耳

| 項目 | 仕様 |
|---|---|
| 長さ | `00_origin.png` の横広垂れ耳の長さ感に合わせる。顔の下端より大きく下へ垂らさない |
| 幅 | 横に広く、顔横から外へ張る。細長い縦耳にしない |
| 形 | 横広の垂れ耳。外側へふくらみ、先端に丸いふわふわ房がある |
| 内側の色 | **薄ピンク `#F5D5D0`**（外側は体色） |

**耳は `00_origin.png` の横広シルエットが識別の核**。Cinnamoroll 的な長い縦耳、
大きすぎる丸耳、顔下まで垂れすぎる耳は別キャラ。

#### 1.2.5 キャンバス内サイズ

| 項目 | 仕様 |
|---|---|
| 全身高 | キャンバス高の **約 70%** |
| 上下マージン | 各約 15% |
| 体幹中心位置 | キャンバス中央 |
| 足元基準ライン | キャンバス底から 15% |

### 1.3 固定デザイン要素（**変更禁止**）

以下は **どのポーズ・どの emotion でも必ず描かれる**。欠けていたら不合格。

| 要素 | 仕様 | 色 |
|---|---|---|
| 体毛 | 明るいクリーム色のふわふわ（実測） | `#FEFBE7` ± 3% |
| 垂れ耳 | `00_origin.png` と同じ横広の垂れ耳。内側は自然に見える角度だけ薄ピンク | 外：体色 / 内：`#F5D5D0` |
| アホ毛 | 頭頂から 1 本。低く後ろへ流れる丸いカール | 体色 |
| 前髪 | 目の上に短い房。中央房 + 左右房を `00_origin.png` の密度で描く | 体色 |
| 目 | 大きな縦楕円、**茶色〜橙茶の瞳グラデ**、外側に白目の余白、白ハイライト | `#502C1B` / 白 |
| 頬 | 左右に薄ピンクの丸い頬染め | `#F5B5B0` |
| 鼻 | **極小の点、または簡素な逆 V**。目立たない | `#3A2A1A` |
| 手足の肉球 | 手足先端に小さなピンク肉球パッド。指・爪は描かない | `#F5B5B0` ± 5% |
| **おむつ** | 下半身を覆う白いおむつ。**中央に茶色の肉球プリント**（実測：明るめの茶） | 地：`#FAFAFA` / 肉球：`#A27250` |
| 尻尾 | **体色のフサフサ**（先端色違いなし）。**根元にコンパクトなピーチピンクのリボン/結び** | 体：体色 / リボン：`#F9C4A1` |

**重要ポイント**：
- おむつは **下半身（お尻〜腹下）を覆う布**、首元のスタイではない
- 尻尾の色特徴は **先端** ではなく **根元のリボン/結び** である。
  大きな蝶結び・ハート形・花びら形にしない
- 肉球は 2 種類ある：
  - 手足先端の **小さなピンク肉球パッド**
  - おむつ中央の **茶色い肉球プリント**
  どちらも必要だが、手足の肉球を指・爪・リアルな足裏として描かない

### 1.4 個体差として変えて OK な要素

後段で runtime 合成するため、**基本 PNG では付けない**。
ただし **将来的な色 tint の幅として以下は許容**：

| 要素 | 個体差の幅 |
|---|---|
| 体色 tint | hue ±15°、saturation ±10%（中間色のみ、原色 NG） |
| サイズ | 0.9x - 1.1x |
| 装備小物 | `40_accessory_library.md` の 20 種から 1 個 overlay |

### 1.5 表情の描き分け原則

感情ごとに以下を変える：

| 感情軸 | 変える部位 |
|---|---|
| 目 | 丸開き / 細目 / ハの字 / x_x / 涙目 / ぐるぐる |
| 口 | 閉じ / 笑み / Ω / 三角 / 舌出し |
| 眉 | 通常見えない、必要な時のみ前髪の隙間から |
| 頬 | 赤み強弱 |

既存 01-09 の顔の描き分けを参照して踏襲。

ただし、既存スプライトの用途名と見た目を混同しないこと：

- `05_sulking.png` は legacy では `sleep` に割り当たっているが、見た目は
  転んだ瞬間・へたり込み・すね倒れ。穏やかな純睡眠の顔ではない
- `08_sleepy.png` は `exhausted` 用で、殴られ後・昏睡しかけ・意識もうろうの顔。
  穏やかな純睡眠の顔ではない
- 純睡眠は `28_sleep_curl` / `29_sleep_flat` / `30_nap_sitting` で描き、
  閉じ目・小さい口・リラックスした耳にする。x_x 目、舌出し、衝撃星、あざ、
  Zzz 文字は使わない

## 2. フラナ（Furana / ママ）

### 2.1 種族定義

- ちびわふと **同種族だが別体型**の大人個体
- 語尾は同じく「〜わふ」
- ちびわふ達の母親ポジション、凛とした監督者

### 2.2 ちびわふとの造形上の違い

**単純にちびわふを拡大したものではない**。プロポーションが違う。

| 項目 | ちびわふ | フラナ |
|---|---|---|
| 頭 vs 体 の割合 | `00_origin.png` のデザイン性優先。目安は頭 55-60% / 胴 30-35% / 脚 10%（**頭：体 ≒ 1.5 : 1**、頭が体より明確に大きい） | 頭 55% / 胴 35% / 脚 10%（**頭：体 ≒ 1.2 : 1**、頭がやや大きい、ちびわふより体がわずかに長い） |
| 全体シルエット | 頭がドンと大きい立ち chibi | **ちびわふより体がやや縦長、ただし依然として頭 > 体** |
| サイズ（画面比） | ちびわふ 1.0x | **ちびわふの約 1.8x**（並べた時の高さ比。単独発注時はキャンバス 70% で統一） |
| 関節の描写 | なし | なし（**維持**） |
| 指・爪 | なし | なし（**維持**） |
| 首 | なし | なし（**維持**） |

⚠ フラナだからといって人間大人体型に寄せない。**手足は短いまま、指・関節・首は描かない**。
あくまで「縦に伸びたちびわふ」の延長にある別キャラ。

### 2.3 フラナ固定デザイン要素（**変更禁止**）

| 要素 | 仕様 | 色 |
|---|---|---|
| 体毛 | **クリームと白の中間**（ちびわふより明確に白め、実測） | `#FEFAEF` ± 3% |
| 垂れ耳 | ちびわふと同じ形・長さ、内側薄ピンク | 外：体色 / 内：`#F5D5D0` |
| アホ毛 | 頭頂から 1 本 | 体色 |
| 前髪 | 目の上に短いぱっつん | 体色 |
| **目** | 大きな丸、**鮮やかな赤い瞳**に白ハイライト 2 点 | `#D33023` / 白 |
| 頬 | 左右に薄ピンク頬染め（ちびわふより控えめ） | `#F5B5B0` |
| 鼻 | 極小の点または逆 V | `#3A2A1A` |
| **首輪** | **赤い首輪を首元に巻く**。正面中央に **アンティーク金の鈴** が下がる | 首輪：`#D12E21` / 鈴：`#EFC573` |
| **おむつ** | 下半身の白いおむつ。**中央に鮮やかなピンクの肉球プリント**（ちびわふは茶色） | 地：`#FAFAFA` / 肉球：`#FC97A6` |
| 尻尾 | **体色のフサフサ**。**根元にピーチピンクのリボン**（ちびわふと同じリボン） | 体：体色 / リボン：`#F9C4A1` |

### 2.4 フラナの表情

ちびわふの「優しげ・泣き虫」とは対照的に、**凛として クール な監督者**。

| 要素 | 仕様 |
|---|---|
| 基本表情 | 落ち着いた閉じ口、目は真っ直ぐ前を見る、凛とした佇まい |
| 笑顔 | 小さく控えめ（ちびわふのように大きく笑わない） |
| 怒り | 眉を寄せてじっと睨む（ちびわふのように Ω 口を開けない） |
| 悲しみ | 静かに目を伏せる（号泣しない） |

**「疲れ気味・半目」は誤り**。凛として目をしっかり開いてる。

### 2.5 リファレンス

- `public/furana/01_normal.png` が絶対基準
- ちびわふと並んだ時のスケール比は既存画像で検証

## 3. 禁則事項（アンチデザイン）

発注時に **明示的に排除するキーワード**：

| カテゴリ | NG 要素 |
|---|---|
| 絵柄 | watercolor / storybook / picture book / painterly / sketchy / crayon |
| 画風 | photorealistic / 3D render / anime-only / manga-only |
| **造形** | **首を描く** / **肘・膝・肩・足首の関節線を描く** |
| **造形** | **指を描く** / **爪を描く** / 手足のピンク肉球をリアルな犬足裏・指分割として描く |
| **造形** | **articulated body の解剖学**（puppet 的リアル体型） |
| **造形** | **人間大人体型**（くびれ・長い四肢・首） |
| **造形** | 頭を極端に小さくする / シルエットを縦に細長くする |
| キャラ | 人間の服を着せる / 靴を履かせる / 武器（小物以外） |
| 変形 | 耳を `00_origin.png` と違う形にする / 尻尾を長すぎる / 体色を原色にする |
| 構造 | 瞳孔を細くする / 歯を見せる（舌は OK） |
| 背景 | 環境背景を描く（単体発注時）/ ground shadow 焼き込み |
| **用語の混同** | **"bib"（スタイ）と表現しない → "diaper"（おむつ）** |
| **用語の混同** | **尻尾の "tip"（先端）に色を付けない → "base"（根元）にリボン** |

## 4. この仕様書の使い方

発注時は以下の順でプロンプトを組む：

```
[50_prompt_templates.md からマスタープロンプト]
 ↓
[10_character_design.md § 1.2 造形 + § 1.3 固定要素]  ← ちびわふ発注時
   または
[10_character_design.md § 2.2 造形差分 + § 2.3 固定要素]  ← フラナ発注時
 ↓
[10_character_design.md § 3 禁則事項]
 ↓
[30_pose_catalog.md から該当ポーズ記述]
 ↓
[20_technical_spec.md から納品形式要件]
 ↓
添付: public/chibiwafu/00_origin.png または public/furana/01_normal.png
```

プロンプト全体は 600-900 words に収まる設計。

## 5. 変更履歴

- v0.1 初版（既存 01-09 を基準にデザイン固定要素を抽出）
- v0.2 § 1.2 造形・シルエット仕様を追加。
  v0.1 では色・装飾は規定したが形そのものを規定しておらず、
  AI が puppy chibi テンプレで articulated body を描いて毎回失敗していた。
- v0.3 **実画像を再精査して致命的な誤りを修正**：
  - ちびわふの「スタイ」は **おむつ**（下半身）の誤記だった
  - 尻尾の「先端オレンジ」は **根元のピンクリボン**の誤記だった
  - 鼻の「三角」は「極小の点/簡素」に緩和
  - 造形の v0.2 改訂が過度に「ブロブ化」に寄っていたのを緩和
    （ちゃんと立つ chibi、脚・腕は見える）
  - **フラナ仕様がほぼ全て捏造だった**ので全面書き直し：
    - エプロン着用 → ❌ 実際は **赤い首輪 + 金色の鈴**
    - 茶色の目 → ❌ 実際は **赤い目**
    - 優しげ疲れ顔 → ❌ 実際は **凛としてクール**
    - ちびわふの 1.8x → ❌ 実際は **プロポーションから違う（約 2 頭身）**
    - おむつ記述なし → ✅ 着用（**ピンクの肉球**、ちびわふは茶色）
    - 尻尾リボン → ✅ ちびわふと同じく根元にピンクリボン
  - § 3 NG に「用語の混同」項目追加（bib/diaper、tail tip/base）
- v0.4 **実画像を Pillow + numpy で実測して全色値・頭身比を修正**：
  - ちびわふ体色 `#F5E6D3` → `#FEFBE7`（実測はより明るい）
  - ちびわふ茶色肉球 `#8B5A2B` → `#A27250`
  - ちびわふ尻尾リボン `#F2A576` → `#F9C4A1`
  - ちびわふ瞳 `#4A2A1A` → `#502C1B`
  - フラナ体色 `#F5EFE2` → `#FEFAEF`
  - フラナ赤目 `#C0363A` → `#D33023`（より鮮やか）
  - フラナ赤首輪 `#B82B2B` → `#D12E21`（より鮮やか）
  - フラナ鈴 `#E8C84A` → `#EFC573`（アンティーク金、もっと渋め）
  - フラナピンク肉球 `#F5B5B0` → `#FC97A6`（鮮やかなピンク、想定より濃い）
  - フラナ尻尾リボン `#F2A576` → `#F9C4A1`（ちびわふと共通色に統一）
  - **頭身比の修正**：ちびわふ「頭 45-50%」→「頭 60%」、フラナ「頭 40-45%」
    →「頭 55%」。実測すると ちびわふもフラナも **頭が体より大きい逆転頭身**。
    フラナを「頭 ≦ 体」と書いていたのは誤りで、正しくは「頭 ≧ 体（ちびわふより僅差）」
- v0.5 `01_normal.png` の再現性優先へ修正：

# キャラクターデザイン仕様

既存 01-09 の絵柄を **唯一の真実の源（source of truth）** とする。
新規発注は全て既存 PNG と並べて違和感が出ない状態を合格基準とする。

**リファレンス画像（発注時に必ず添付）**：
- `public/chibiwafu/01_normal.png`（ちびわふ基準）
- `public/furana/01_normal.png`（フラナ基準）

> ⚠ **ちびわふとフラナは別体型**。フラナは「ちびわふの拡大版」ではなく、
> プロポーション・装備・目の色が違う別キャラクター。§ 1 と § 2 を独立に読む。

---

## 1. ちびわふ（Chibiwafu）

### 1.1 種族定義

- 垂れ耳のプードル風の ちびもの
- 2D ゲーム用の chibi / SD 頭身
- 口語では「くそざこ」「ちびわふ」
- 語尾は「〜わふ」

### 1.2 プロポーションと造形

Sanrio の **ポチャッコ / シナモロール** 系の「ずんぐり立ち chibi」。
Kirby のような純ブロブでもなく、Disney puppy のような articulated body でもない。
**ちゃんと 2 本足で立つ、ただし手足は短い**。

#### 1.2.1 頭身比

| 部位 | 全身に占める縦の割合 |
|---|---|
| 頭部（耳の上端まで） | 約 **45-50%** |
| 胴体 | 約 **30-35%** |
| 脚部（露出） | 約 **15-20%** |

**頭：体（胴+脚）比 ≒ 1.05 : 1.0**（頭がわずかに大きい）。
「2 頭身」「3 頭身」と書くと人間 chibi 解釈されるので、
**「頭が体とほぼ同じか、わずかに大きい」** と明記する。

#### 1.2.2 首

**描かない**。頭が胴の上に直接乗る。首の輪郭線・首のくびれは NG。
Hello Kitty / ポチャッコ のように頭と体が直結。

#### 1.2.3 手足

**ちゃんと 2 本の腕と 2 本の脚が生えている**、ただし：

| 部位 | 仕様 |
|---|---|
| 腕 | 胴の脇から下に向かって生える。長さ ≒ 胴の縦半分。肘・肩の関節線は描かない |
| 脚 | 胴の下から 2 本明確に出る。長さ ≒ 全身の 15-20%。膝・足首の線は描かない |
| 手の先 | **指なし・爪なし・肉球パッド線なし**。先端は単純な丸で終わる |
| 足の先 | 同様、丸く終わる |

**スタブ（切り株）的な "肉球コブ" ではなく、短めだが明確な手足**。
腕は振れるし、脚は立てるし、座れる。ただし解剖学的な関節線は描かない。

#### 1.2.4 耳

| 項目 | 仕様 |
|---|---|
| 長さ | **顔の縦幅とほぼ同じ**（顎の位置まで届く） |
| 幅 | 顔幅の約 30% |
| 形 | 楕円が下に垂れ下がる、先端は丸い |
| 内側の色 | **薄ピンク `#F5D5D0`**（外側は体色） |

**耳が顔と同じくらいデカい** のがキャラ識別の核。短くしたら別キャラ。

#### 1.2.5 キャンバス内サイズ

| 項目 | 仕様 |
|---|---|
| 全身高 | キャンバス高の **約 70%** |
| 上下マージン | 各約 15% |
| 体幹中心位置 | キャンバス中央 |
| 足元基準ライン | キャンバス底から 15% |

### 1.3 固定デザイン要素（**変更禁止**）

以下は **どのポーズ・どの emotion でも必ず描かれる**。欠けていたら不合格。

| 要素 | 仕様 | 色 |
|---|---|---|
| 体毛 | クリーム色のふわふわ | `#F5E6D3` ± 5% |
| 垂れ耳 | 長く垂れ、内側は薄ピンク | 外：体色 / 内：`#F5D5D0` |
| アホ毛 | 頭頂から 1 本ぴょこっと立つ | 体色 |
| 前髪 | 目の上に短いぱっつん | 体色 |
| 目 | 大きな丸、**茶色**の瞳に白ハイライト 2 点 | `#4A2A1A` / 白 |
| 頬 | 左右に薄ピンクの丸い頬染め | `#F5B5B0` |
| 鼻 | **極小の点、または簡素な逆 V**。目立たない | `#3A2A1A` |
| **おむつ** | 下半身を覆う白いおむつ。**中央に茶色の肉球プリント** | 地：`#FAFAFA` / 肉球：`#8B5A2B` |
| 尻尾 | **体色のフサフサ**（先端色違いなし）。**根元に桃色リボン** | 体：体色 / リボン：`#F2A576` |

**重要ポイント**：
- おむつは **下半身（お尻〜腹下）を覆う布**、首元のスタイではない
- 尻尾の色特徴は **先端** ではなく **根元のリボン** である
- 肉球プリントは **おむつの中央** に配置される

### 1.4 個体差として変えて OK な要素

後段で runtime 合成するため、**基本 PNG では付けない**。
ただし **将来的な色 tint の幅として以下は許容**：

| 要素 | 個体差の幅 |
|---|---|
| 体色 tint | hue ±15°、saturation ±10%（中間色のみ、原色 NG） |
| サイズ | 0.9x - 1.1x |
| 装備小物 | `40_accessory_library.md` の 20 種から 1 個 overlay |

### 1.5 表情の描き分け原則

感情ごとに以下を変える：

| 感情軸 | 変える部位 |
|---|---|
| 目 | 丸開き / 細目 / ハの字 / x_x / 涙目 / ぐるぐる |
| 口 | 閉じ / 笑み / Ω / 三角 / 舌出し |
| 眉 | 通常見えない、必要な時のみ前髪の隙間から |
| 頬 | 赤み強弱 |

既存 01-09 の顔の描き分けを参照して踏襲。

## 2. フラナ（Furana / ママ）

### 2.1 種族定義

- ちびわふと **同種族だが別体型**の大人個体
- 語尾は同じく「〜わふ」
- ちびわふ達の母親ポジション、凛とした監督者

### 2.2 ちびわふとの造形上の違い

**単純にちびわふを拡大したものではない**。プロポーションが違う。

| 項目 | ちびわふ | フラナ |
|---|---|---|
| 頭 vs 体 の割合 | 頭 45-50% / 胴脚 50-55%（**頭：体 ≒ 1.05 : 1.0**、頭がわずかに大きい） | 頭 40-45% / 胴脚 55-60%（**頭：体 ≒ 0.9-1.0 : 1.0**、体がわずかに大きい、体が縦に伸びる） |
| 全体シルエット | ずんぐり立ち chibi | **やや縦長の立ち姿、ただし手足は短め** |
| サイズ（画面比） | ちびわふ 1.0x | **ちびわふの約 1.8x**（並べた時の高さ比。単独発注時はキャンバス 70% で統一） |
| 関節の描写 | なし | なし（**維持**） |
| 指・爪 | なし | なし（**維持**） |
| 首 | なし | なし（**維持**） |

⚠ フラナだからといって人間大人体型に寄せない。**手足は短いまま、指・関節・首は描かない**。
あくまで「縦に伸びたちびわふ」の延長にある別キャラ。

### 2.3 フラナ固定デザイン要素（**変更禁止**）

| 要素 | 仕様 | 色 |
|---|---|---|
| 体毛 | **クリームと白の中間**（ちびわふより白め） | `#F5EFE2` ± 5% |
| 垂れ耳 | ちびわふと同じ形・長さ、内側薄ピンク | 外：体色 / 内：`#F5D5D0` |
| アホ毛 | 頭頂から 1 本 | 体色 |
| 前髪 | 目の上に短いぱっつん | 体色 |
| **目** | 大きな丸、**赤い瞳**に白ハイライト 2 点 | `#C0363A` / 白 |
| 頬 | 左右に薄ピンク頬染め（ちびわふより控えめ） | `#F5B5B0` |
| 鼻 | 極小の点または逆 V | `#3A2A1A` |
| **首輪** | **赤い首輪を首元に巻く**。正面中央に **金色の鈴** が下がる | 首輪：`#B82B2B` / 鈴：`#E8C84A` |
| **おむつ** | 下半身の白いおむつ。**中央にピンクの肉球プリント**（ちびわふは茶色） | 地：`#FAFAFA` / 肉球：`#F5B5B0` |
| 尻尾 | **体色のフサフサ**。**根元にピンクリボン**（ちびわふと同じ） | 体：体色 / リボン：`#F2A576` |

### 2.4 フラナの表情

ちびわふの「優しげ・泣き虫」とは対照的に、**凛として クール な監督者**。

| 要素 | 仕様 |
|---|---|
| 基本表情 | 落ち着いた閉じ口、目は真っ直ぐ前を見る、凛とした佇まい |
| 笑顔 | 小さく控えめ（ちびわふのように大きく笑わない） |
| 怒り | 眉を寄せてじっと睨む（ちびわふのように Ω 口を開けない） |
| 悲しみ | 静かに目を伏せる（号泣しない） |

**「疲れ気味・半目」は誤り**。凛として目をしっかり開いてる。

### 2.5 リファレンス

- `public/furana/01_normal.png` が絶対基準
- ちびわふと並んだ時のスケール比は既存画像で検証

## 3. 禁則事項（アンチデザイン）

発注時に **明示的に排除するキーワード**：

| カテゴリ | NG 要素 |
|---|---|
| 絵柄 | watercolor / storybook / picture book / painterly / sketchy / crayon |
| 画風 | photorealistic / 3D render / anime-only / manga-only |
| **造形** | **首を描く** / **肘・膝・肩・足首の関節線を描く** |
| **造形** | **指を描く** / **爪を描く** / **肉球パッド線を手足に描く** |
| **造形** | **articulated body の解剖学**（puppet 的リアル体型） |
| **造形** | **人間大人体型**（くびれ・長い四肢・首） |
| **造形** | 頭を極端に小さくする / シルエットを縦に細長くする |
| キャラ | 人間の服を着せる / 靴を履かせる / 武器（小物以外） |
| 変形 | 耳を短くする / 尻尾を長すぎる / 体色を原色にする |
| 構造 | 瞳孔を細くする / 歯を見せる（舌は OK） |
| 背景 | 環境背景を描く（単体発注時）/ ground shadow 焼き込み |
| **用語の混同** | **"bib"（スタイ）と表現しない → "diaper"（おむつ）** |
| **用語の混同** | **尻尾の "tip"（先端）に色を付けない → "base"（根元）にリボン** |

## 4. この仕様書の使い方

発注時は以下の順でプロンプトを組む：

```
[50_prompt_templates.md からマスタープロンプト]
 ↓
[10_character_design.md § 1.2 造形 + § 1.3 固定要素]  ← ちびわふ発注時
   または
[10_character_design.md § 2.2 造形差分 + § 2.3 固定要素]  ← フラナ発注時
 ↓
[10_character_design.md § 3 禁則事項]
 ↓
[30_pose_catalog.md から該当ポーズ記述]
 ↓
[20_technical_spec.md から納品形式要件]
 ↓
添付: public/chibiwafu/01_normal.png または public/furana/01_normal.png
```

プロンプト全体は 600-900 words に収まる設計。

## 5. 変更履歴

- v0.1 初版（既存 01-09 を基準にデザイン固定要素を抽出）
- v0.2 § 1.2 造形・シルエット仕様を追加。
  v0.1 では色・装飾は規定したが形そのものを規定しておらず、
  AI が puppy chibi テンプレで articulated body を描いて毎回失敗していた。
- v0.3 **実画像を再精査して致命的な誤りを修正**：
  - ちびわふの「スタイ」は **おむつ**（下半身）の誤記だった
  - 尻尾の「先端オレンジ」は **根元のピンクリボン**の誤記だった
  - 鼻の「三角」は「極小の点/簡素」に緩和
  - 造形の v0.2 改訂が過度に「ブロブ化」に寄っていたのを緩和
    （ちゃんと立つ chibi、脚・腕は見える）
  - **フラナ仕様がほぼ全て捏造だった**ので全面書き直し：
    - エプロン着用 → ❌ 実際は **赤い首輪 + 金色の鈴**
    - 茶色の目 → ❌ 実際は **赤い目**
    - 優しげ疲れ顔 → ❌ 実際は **凛としてクール**
    - ちびわふの 1.8x → ❌ 実際は **プロポーションから違う（約 2 頭身）**
    - おむつ記述なし → ✅ 着用（**ピンクの肉球**、ちびわふは茶色）
    - 尻尾リボン → ✅ ちびわふと同じく根元にピンクリボン
  - § 3 NG に「用語の混同」項目追加（bib/diaper、tail tip/base）

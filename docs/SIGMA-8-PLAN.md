# Sigma-8 Roadmap v2: 低解像度タイル箱庭地形リワーク

## 目的

Sigma-8 の目的は、くそざこ村の地形改造を「見て分かる、触って気持ちいい、失敗して笑える」
遊びに作り直すこと。M2 の 8 週間では高級 3D 表現ではなく、商業インディー品質の
**統一された低解像度タイル箱庭**を目指す。

勝ち筋は、リアルな岩肌ではなく次の体験を成立させること。

- 盛る、削る、坂道化で地形が即座に読める形で変わる
- 崖、坂、水、泥、雪のルールが見た目と一致する
- 切り土で壁を崩し、坂道化で道が開通する
- 雨や雪で水位、泥、崩落、移動リスクが変わる
- ちびわふが異常に弱く、環境判断ミスで死ぬ

## 固定判断

| 項目 | 採用 |
|---|---|
| エンジン | M2 は Three.js 継続。M3 で Unity 縦切り検証 |
| 見た目 | 低解像度スタイライズドタイル箱庭 |
| 参照感 | A Short Hike 寄りの明るさ、ただし PBR は捨てる |
| 地形材質 | `grass` / `soil` / `rock` / `sand` / `snow` の 5 種 |
| 状態表現 | `wetness` / `mud` / `snowCoverage` は材質ではなく overlay |
| 斜面 | 滑らかな自由斜面は禁止。段々地形 + 明示的な坂タイル |
| 崖 | 高さ差 2 段以上は絶対崖。InstancedMesh の壁面タイルで明示 |
| 通行 | 描画、A*、水流、事故判定が同じ地形ルールを見る |
| シェーダ | texture atlas lookup + 簡易陰影 + overlay |
| 捨てるもの | PBR、normal、roughness、splat blend、tri-planar、SSAO、LUT、Bloom |
| アセット | ChatGPT 生成を主軸。AI 原案 + ゲーム内検品 + 必要なら手動補正 |
| UI | M2 正式スコープ。Week 1 から地形実装と並行 |
| 土量保存則 | 導入しない |

## 画風基準

初期モック: [sigma-8-mockup.png](sigma-8-mockup.png)

Week 0 の画風判断は、単独タイルではなく画面全体で行う。最低限、次を同じ画面に置く。

- grass / soil / rock / water / cliff
- 坂タイルまたは段差
- ちびわふ 1-3 体
- ground prop 2 種
- 雨または雪 overlay
- 下ツールバー、右設定パネル、左上時間 HUD、ログ

この画面が売れそうに見えない場合、タイル枚数を増やす前に画風を直す。

## 地形ルール

M2 は連続標高ではなく、25 単位刻みの段階地形として扱う。

- `elev` は 0-255 の数値だが、通常操作は 25 単位で丸める
- 高さ差 0: 通行可
- 高さ差 1 段: 坂タイルがあれば通行可、なければ不可または危険通行
- 高さ差 2 段以上: 崖、通行不可
- 水は低い隣接タイルへ流れる
- `wetness` / `mud` / `snowCoverage` は移動 cost と事故確率に影響する

坂タイルは「見た目の斜面」ではなく「通行できる斜面」を表す。1 タイル 1 方向のみ。

```ts
type RampDir = 'N' | 'S' | 'E' | 'W';
```

## M2 ロードマップ

### Week 0: 画面モックと仕様固定

目的: 画風、UI、地形ルールを実装前に固定する。

- `docs/SIGMA-8-PLAN.md` を v2 に更新
- `docs/SIGMA-8-DEVELOPMENT-SPEC.md` を作成
- 画面モックを `docs/sigma-8-mockup.png` として保存
- ChatGPT で追加モックを 2-3 枚生成し、画風を確定
- 草タイル単体ではなく、画面モックで採用可否を決める
- UI の基本構成を決める

完了条件:

- 画面モックを基準画像として共有できる
- PBR へ戻らないこと、段々地形 + 坂タイルで進めることが文書化済み

### Week 1-2: Sigma-8-a 地形データ拡張 + UI 骨格

目的: 段々地形、坂タイル、状態 overlay のデータ土台を作る。

- `TerrainMaterial` を 5 種へ整理
- `TerrainTile` に `ramp`, `wetness`, `mud`, `snowCoverage` を追加
- `elev` を 0-255 へ拡張し、編集操作は 25 単位へ正規化
- `RAISE_ELEV_AMOUNT` を 25 へ変更
- generator の標高レンジを再調整
- save v13 -> v14 migration を実装
- 時間 HUD の最小版を追加
- 下ツールバーと右設定パネルの枠を追加
- 画面モック承認後、タイル 5 種 + 崖壁 + 坂タイルの発注へ進む

完了条件:

- 1 回の盛り/削りで 1 段変化が明確に見える
- `ramp` を保存/ロードできる
- 左上に季節、日数、時刻、天気が表示される

### Week 3-4: Sigma-8-b 崖物理化 + A* + 坂道化

目的: 見た目の段差と通行ルールを完全一致させる。

- タイル差分ベースの通行判定を実装
- A* を 100x57 grid に導入
- path job queue を実装し、1 フレーム最大 4 件程度に制限
- `terrainVersion` で path cache を無効化
- 高さ差 2 段以上の境界に崖壁 InstancedMesh を表示
- 高さ差 1 段 + `ramp` ありの場合だけ坂として通す
- 坂道化ブラシの最小版を実装
- 工事ポーズ 6 種を発注

完了条件:

- ちびわふが崖を登らない
- 坂タイルを作ると通れる
- 切り土で高さ差を減らし、坂道化で道が開通する
- A* の失敗箇所を UI/マーカーで確認できる

### Week 5-6: Sigma-8-c タイル atlas + 状態 overlay + props

目的: 地形を低解像度タイル箱庭として見せる。

- terrain texture atlas を読み込む
- `materialId` + `ramp` + overlay で地形を描く
- wetness / mud / snowCoverage overlay を実装
- 水流表示をタイル上に重ねる
- grass / bush / flower の ground prop InstancedMesh を導入
- terraform 時に props を消す/再生成する
- ground prop 10 種を発注
- UI のツール設定パネルを実機操作に接続

完了条件:

- grass / soil / rock / sand / snow / cliff / ramp / water が画面上で即判別できる
- 雨で wetness と mud が見た目に反映される
- 雪で snowCoverage が見た目に反映される
- props が地形改造と矛盾しない

### Week 7: Sigma-8-d ブラシ UX + UI 統合

目的: 地形開発ゲームとしての操作感を完成させる。

- 6 ブラシを実装
  - 盛る
  - 削る
  - 平坦化
  - スムーズ
  - 坂道化
  - 水路
- drag paint を実装
- ゴーストプレビューを実装
- 変更後の高さ、坂方向、通行可否をプレビュー
- undo / redo 50 ステップ
- progress 連続補間アニメ
- UI のツールバー、設定パネル、時間 HUD、ログを統合

完了条件:

- マウスドラッグで大規模地形編集ができる
- 失敗しても undo で戻せる
- 坂道化で道が開通する瞬間が明確に見える

### Week 8: Sigma-8-e Polish + M2 判定

目的: M2 として遊べる品質に締める。

- 工事ポーズを統合
- 「みちができたわふ！」など道開通反応を追加
- 崩落、泥、雪、水流の視認性を調整
- 30 分 headless sim を実行し、死因/食料/寿命の破綻を確認
- fps 60 目標でプロファイル
- M2 判定プレイを行う

完了条件:

- 切り土で見た目が変わる
- 崖が壁として機能する
- 坂タイルで道が開通する
- 雨/雪/泥/水のリスクが HUD と画面で読める
- 触っていて気持ちいい

## UI スコープ

M2 で UI は後回しにしない。最低限、次を入れる。

- 下ツールバー: 盛る / 削る / 平坦化 / スムーズ / 坂道化 / 水路 / 建設
- 右設定パネル: ブラシ半径、強さ、目標高度、坂方向、undo/redo
- 左上 HUD: 季節、日数、時刻、天気、水位、崩落危険、夜までの残り
- 左下ログ: 死亡、事故、道開通、作業失敗
- ミニマップ: M2 では任意。ただし余裕があれば高低差、水、崖を表示

時間 HUD の基準表示:

```text
春 12日 14:30  晴れ  水位: やや高い  崩落危険
夜まで 3:20
```

## アセット発注ロードマップ

| 時期 | 発注 | 用途 |
|---|---|---|
| Week 0 | フル画面モック 2-3 枚 | 画風固定 |
| Week 1 | タイル 5 種、崖壁、坂タイル | atlas 実装 |
| Week 3 | 工事ポーズ 6 種 | polish |
| Week 4 | ground prop 10 種 | 地形密度 |

AI 生成アセットは必ずゲーム内で検品する。シームレス性、縮小表示、彩度、ちびわふとの整合が
崩れる場合は再発注または補正する。

## M2 後の分岐

Week 9 に M2 評価を行う。

- OK: Three.js のまま Sigma-9 へ進む
- やや不満: Unity 縦切りを 1-2 週間で作る
- 致命的に物足りない: 地形 UX と市場ポジションを再検討する

Unity 縦切りでは次だけ再現する。

- 100x57 grid
- elev 0-255 / 25 単位
- brush
- cliff wall
- ramp tile
- water 1 pass
- chibi billboard 10 体
- A*
- rain/snow

気持ちよく動くなら本移行、苦しければ Three.js 継続。

## 禁止事項

- M2 中に PBR / normal / roughness / tri-planar へ戻らない
- 滑らかな自由斜面を復活させない
- 見た目の坂と通行可能な坂を別々にしない
- UI を Week 7 まで放置しない
- 単独タイルだけで画風判断しない
- アセット枚数を増やしてルールの読みにくさを隠さない
